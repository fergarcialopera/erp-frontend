# Specs — requisitos y evidencias

Carpeta opcional para especificaciones funcionales usadas por agentes y humanos.

## Qué poner aquí

- Requisitos y criterios de aceptación de una feature.
- Planes **aprobados** (copia o resumen del plan acordado).
- Evidencias de verificación relevantes (cuando aporte trazabilidad).

## Qué no poner

- Código fuente.
- Duplicar `.ai/PROJECT.md` o el README.
- Documentación que solo repite lo obvio del código.

## Convención sugerida

Un archivo por iniciativa, por ejemplo:

`YYYY-MM-DD-nombre-corto.md`

Plantilla mínima:

```markdown
# Título

## Objetivo
## Criterios de aceptación
## Fuera de alcance
## Plan aprobado
## Evidencias
```
